# Architecture outcome

Bevy Stylized owns its product crates, asset preparation, runtime data mapping,
reference capture and validation. First-party synthetic and skinned fixtures are
its mandatory public test inputs. External family qualification uses explicit,
hash-verified original sources and project-owned recipes.

Independent upstream behavior, previously approved production images and semantic
contract tests answer different questions. Retired implementation history is
retained for attribution and migration evidence, not as a build prerequisite.

The remaining visual, platform and publication qualifications keep their actual
status. Engineering independence does not silently close unrelated release gates.
