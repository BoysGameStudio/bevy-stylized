# 静态角色对比计划自审

2026-09-14，计划 v2。依据当前源码检查计划的可实施性、验证真实性和范围边界。
本文件记录计划审查，不代表方案已经实现或视觉资格已通过。

| 检查项 | v1 风险 | v2 修订 |
|---|---|---|
| 完成条件 | 把产出图片等同视觉一致 | 明确 M1 工具流程与 M2 视觉资格，必需项未验证不得 PASS |
| 项目范围 | 将角色验证扩展成动画/表情系统 | 固定静态范围，只变更光照和相机，保留现有变形回归 |
| 相机 | 两端独立 Aabb 自动取景 | 作者端一次生成共享数值，以轴标验证坐标转换和正交宽高 |
| 光照 | 把 Sun 或 Euler 默认值当作 NPR 方向 | 跟踪控制对象到实际 shader 消费链，并做方向单变量校准 |
| 色彩 | 同数值背景及曝光被误认等价 | 记录线性/sRGB、EV/倍率、gamma/display/alpha，先做色块校准 |
| 版本 | 3.6.4 作者图覆盖 3.6.2 reference | 两条输入与 case 保留独立身份，原门槛和失败继续报告 |
| 采样 | 等帧数或同名 AA 参数被误认等价 | 记录实际算法与设置，捕获就绪和重复性单独验证 |
| 阴影指标 | 多色贴图被中位亮度代理当成阴影 | 保留旧算法结果，另行验证语义 mask；无法证明则未验证 |
| 空 mask | 双空集合 IoU=1 制造假通过 | 必需前景及侧光覆盖；无阴影 case 事前声明，不豁免整套阴影能力 |
| 数据就绪 | 等待固定帧数即截图 | 资产、纹理、材质、pipeline、实际设置均检查，有限超时 |
| 身份与尺寸 | 相同字节长度或请求 JSON 证明一致 | 单独检查宽高，分别记录两端实际设置与全部输入依赖摘要 |
| 归因 | 同时调整相机曝光和 shader | 分层修复与最小失败 fixture，报告完整图和预定 ROI |
| 架构 | 新建角色 crate 或复制 lab shader | 复用正式六 crate 和材质路径；工具契约不冒充 runtime API |
| 隔离 | 仅隔离内通过，未检查宿主受污染 | P6 增加 host→isolation→host 往返，独立 Cargo target |
| 验收 | 新 case 掩盖旧 parity FAIL | 旧 reference、接入、回归与角色 parity 分开，数量核实 |
| 无界工作 | 为指标全绿不断扩大 scope | 配方外需求交付最小证据和独立计划，不宣称 M2 完成 |

审查结论：计划没有已知的职责冲突；P2 的实际光照求值和 P4 的语义 mask 可靠性
属于必须用实验解决的不确定性，已设置明确出口。执行前不承诺角色能达到既定
parity 门槛，也不以此为理由降低门槛。计划供用户检视。
